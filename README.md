#Landing Page Viajes

Proyecto web desarrollado como práctica de diseño y desarrollo frontend en grupo.

## Características principales

- Diseño moderno y responsive
- Menú adaptable para móviles
- Secciones informativas de viajes
- Animaciones e interacción con JavaScript
- Diseño atractivo con CSS

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
